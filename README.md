# TuneRelay

A lightweight desktop workflow for sending music discoveries to a Navidrome library.

## Project status

Planning stage. This repository currently contains project and technology notes only; no application code has been added.

## Direction

- Capture a YouTube link from the browser or clipboard.
- Suggest editable track metadata for review.
- Submit an authorized audio file and its metadata to a private service on the music server.
- Save it into the Navidrome library and request a library scan.

TuneRelay is intended for music the user owns or is otherwise authorized to import. A YouTube URL is used as a discovery/reference link, not as an audio download mechanism.
